# BookinGO - Client Web & Mobile Application

BookinGO client application built with React, Vite, TailwindCSS, and Capacitor.

## Scripts

- `npm run dev` : Démarre le serveur de développement local
- `npm run build` : Compile l'application pour la production
- `npm run preview` : Prévisualise le build de production
- `npm run lint` : Vérification du code avec ESLint
- `npm run test` : Lance la suite de tests avec Vitest
